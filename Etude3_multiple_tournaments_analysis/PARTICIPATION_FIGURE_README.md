# Multiple tournament participation figure

`04_known_talents_multiple_tournaments.R`, in the parent scripts folder, draws Figure S5 from the saved probability table. Rerun only this file to adjust fonts, axes, colours, symbols or figure dimensions. The analytical allocation results and essential interpretation are in Supplement 5.6.

The figure uses B=50; beta=0.4,0.8; phi=0.66,1,1.5; and T=2,...,7. Each line shows the distribution of the number entered k for one available total T. The common horizontal axis decreases from 7 to 1.

To recompute, run `compute_participation.R` and then `summarize_participation.R`. They can be sourced or run from the parent scripts folder or from this analysis folder. The computation requires Rcpp and a working C++ toolchain; both are installed on this computer. Its separate C++ source is `known_talents_participation.cpp`. The nonconcave branch solver is specialized to the two phi=1.5 parameter combinations above at B=50 and T<=7. Other nonconcave combinations require extending its branch logic, rather than just changing the plotting labels.

Probabilities are deterministic integrations over the lognormal talent distribution. Four shifted Halton rules, with 262144 points each, are averaged. The file `participation_many.csv` retains individual shifts and a nested 65536-point calculation; `participation_many_summary.csv` contains the plotted averages, and `participation_many_convergence.csv` compares resolutions. The maximum change after increasing the point count fourfold was 0.0949 percentage points. This observed difference is a convergence diagnostic, not a rigorous error bound. Zeros in the plot are numerical values at this resolution, not proofs that a region is empty.

For phi=1 the allocation and support are explicit. For phi<=1 the support follows from the unique concave optimum. For beta=0.4,phi=1.5, each training payoff is either concave or convex then concave; the strongest talent is necessarily on its concave branch at the optimum. Branch combinations are compared globally, with at most one allocation on a convex branch. For beta=0.8,phi=1.5, a strongest talent at least 0.5 guarantees specialization by convexity and superadditivity. In the remaining cases, at most the strongest talent can be on a convex branch. One-dimensional convex-branch profiles are bounded by chords and compared against concave optima to a relative value tolerance of 1e-9.

The global solver was checked independently against simplex dynamic programming for 15 low-talent, high-talent and mixed examples with 2 to 7 tournaments. The integrated phi=1 probabilities for T=2,3 were checked against separate one-dimensional analytical reductions; their largest difference was 0.005 percentage points. These tests and the nested integration check passed before rendering Figure S5.
